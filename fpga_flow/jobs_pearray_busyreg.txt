# Priority (2): the d7 post-route critical path is
#   g_pe[N].pe_i/cid_reg -> merge compare chain -> busy_c
#     -> 392-input OR -> stage_reg/CE          (33 logic levels, 67% routing)
# so the combinational quiescence signal crosses the whole array and comes back
# into the controller every merging cycle.  SNOW_BUSYREG (added to
# snowflake_pe_array.sv, mirroring the flat core's V2d) drives the stage advance
# from the REGISTERED per-PE busy flags instead, at the cost of one provably
# no-op clock per merging phase (suppressed from the trace by the dbg_valid
# rule, same as V2d).
#
